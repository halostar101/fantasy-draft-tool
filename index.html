    Data & backup

    Player data lives in the repo. Your active work autosaves in this browser; export a backup JSON whenever you want to commit your mocks back to GitHub.

    Player dataset

    The supplied PDF does not include ADP. V1 therefore uses ESPN overall rank as its market/draft-order proxy.

    League replacement levels

    Replacement levels are modeled from required starters, FLEX demand, then seven bench spots filled by the best remaining QB/RB/WR/TE players in ESPN rank order.

    Mock backup

    Export your browser state as draft-backup.json. Replace data/draft-backup.json in the GitHub repo and commit it. A fresh browser will use that repo backup as its starting state.

    V1 methodology

    • VORP: projected points above the modeled replacement player at the same position.
    • Lineup gain: how much a player improves your optimized starting lineup versus replacement placeholders.
    • VONA: VORP lost if you wait for a same-position player expected around your next selection.
    • Gone %: conditional estimate from ESPN rank; useful directionally, not a true ADP probability.
